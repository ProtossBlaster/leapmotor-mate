# Mate 4.0.0-rc.2 — automatic migration

Existing installations migrate during normal startup using their existing identity,
certificates, credentials and database. Common application parameters are included
from the checksum-verified public SDK with license and provenance. No migration
bundle, new login or Desktop shell reinstall is required.

A bounded isolated qualification selects one backend for the whole account. B10
accounts use independent MATE-API when qualified; failed checks, unqualified models
and mixed accounts automatically retain the previous client. No remote command is
replayed through another backend. History and configuration are never replaced.

Includes the changes from PRs #313, #314 and #318, plus regression coverage for
#319's charge-unlock ability 48. REEV retains the existing client while receiving
the parser, telemetry and UI corrections. Missing historical GPS cannot be recreated.

MATE-API remains 0.1.0a8. V3 identifies the cloud command protocol. This candidate
does not promote the stable Docker, Desktop or add-on channels.

## Italiano

Migrazione automatica senza passaggi aggiuntivi: vengono riutilizzati dati,

correzioni delle quattro PR aperte, mantenendo la compatibilità Beta/REEV.

La libreria MATE-API e il prodotto Mate hanno versioni indipendenti. V3 riguarda i
comandi. Questo candidato non aggiorna ancora i canali stabili.
