# v3.15.13 — the maintenance log button opens its form

This release answers [discussion #276](https://github.com/ProtossBlaster/leapmotor-mate/discussions/276).

## What changes

- On the Maintenance page, the `+ Log` button of each service card now opens that card's form
  (date, odometer, note, Save) and places the cursor on the date. Until now the button opened an
  empty box, and it had done so since the page was introduced in v1.22.0.
- The second, grey `✎ Mark this service as done` line under the progress bars is gone. It was the
  only way to reach the form, and one control per card is enough. Its wording stays as the
  button's tooltip.
- Saving works as before: the card shows the new last-done date and odometer, and the next due
  date is recalculated.

Local release verification passed **3,316 tests**, with **no skips**. Four of those tests are new:
they render the real template over the real B10 service pack and check that each card has exactly
one log control, that it opens that card's own form, that the form starts closed, and that no empty
disclosure remains. The page was also exercised in a browser against a demo container: the button
opens the form, a second click closes it, Save records the service, and the page stays within a
375-pixel phone width. Test data was synthetic and no live vehicle-cloud command was sent.

## Update and rollback

- Back up Mate using its existing backup feature before upgrading.
- Docker and Home Assistant use the normal image update while retaining the existing data volume.
- MateDesktop receives the payload through its existing updater; no new shell installer is needed.
- This release changes no database schema, stored data or MQTT entity and needs no migration.
- Rolling back to v3.15.12 requires no data conversion. The empty button and the grey line return.

## Italiano

Nella pagina Manutenzione il pulsante `+ Registra` di ogni scheda non faceva nulla: apriva un
riquadro vuoto, ed era così da quando la pagina esiste (v1.22.0). Il modulo che registra un
intervento stava più in basso, dietro la riga grigia `✎ Registra questo intervento`. Ora il
pulsante apre il modulo della sua scheda e mette il cursore sulla data; la riga grigia doppione non
c'è più, e la sua frase resta come suggerimento sul pulsante. Il salvataggio funziona come prima.

Cambia solo un template: nessuna modifica al database, ai dati salvati o alle entità MQTT. Docker,
add-on Home Assistant e MateDesktop ricevono il normale aggiornamento; il ritorno alla v3.15.12 non
richiede conversioni.
