# v3.15.11 — Release version metadata correction

This corrective patch updates Mate's internal version to match the release metadata.

## What changes

- `MATE_VERSION` now reports `3.15.11` consistently with the changelog and release tag.
- The joined-trip note correction delivered for #279 is unchanged.
- No runtime behavior, dependency, database schema or stored data changes.

Version 3.15.10 was published with the application still reporting 3.15.9 internally. Its
container and Home Assistant packages were distributed successfully, but the version consistency
guard correctly rejected that mismatch. This release resolves it without rewriting the immutable
3.15.10 tag.

## Verification

The version-to-changelog guard and the complete project test suite are run before publication.

## Update and rollback

- Docker and Home Assistant use the normal image update while retaining the existing data volume.
- MateDesktop receives the payload through its existing updater when its shell compatibility gate
  permits it.
- This release requires no migration and changes no user data.
- Rolling back to v3.15.10 requires no data conversion, but Mate will again report 3.15.9 internally.

## Italiano

La v3.15.10 è stata distribuita con il numero interno dell'applicazione ancora impostato a 3.15.9.
Questa patch correttiva allinea il numero interno a **3.15.11** senza modificare la correzione della
#279, le dipendenze, il database o i dati degli utenti. Il tag v3.15.10 resta immutato.
