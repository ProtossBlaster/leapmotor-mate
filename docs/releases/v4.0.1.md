# Mate 4.0.1 — cloud-history translations

Fixes Settings showing `cloud_import_title`, `cloud_import_enabled`, `cloud_import_help` and `cloud_import_save` instead of readable text. The strings existed outside the `translations` dictionary used by the application. Fourteen affected settings/history labels are now in the correct dictionary in all eight locales.

Adds regression coverage for locale structure and the actual runtime translator. No account, data, command or migration behavior changes. Existing Mate 4 migration decisions remain valid; this patch does not repeat cloud qualification.

## Italiano

Corrette le chiavi tecniche visibili nelle Impostazioni: ora vengono mostrati «Storico viaggi cloud», «Importa viaggi dal cloud Leapmotor», la spiegazione e «Salva». Sistemate anche le etichette dello storico interessate dallo stesso errore. Nessuna modifica a dati, credenziali, comandi o migrazione.
