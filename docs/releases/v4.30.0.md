# Mate 4.30.0 — Home Assistant sets the A/C target temperature

Home Assistant can now set the A/C target temperature, as the Commands page always could.

---

## What changes

### Home Assistant sets the A/C target temperature ([#489](https://github.com/ProtossBlaster/leapmotor-mate/issues/489), @michapr)

The car's device in Home Assistant gets a writable number, **AC Target Temperature**, from 18 to 32 °C in
steps of 1.

- **It sends the Commands page's own command.** Only the target changes: the climate keeps the mode, fan
  speed and recirculation of the car's last reading. A climate in AUTO stays in AUTO; on a T03, which
  ignores an AUTO command (#67), it sends manual cooling, as the page does.
- **It shows the car's target**: it reads the same value as the *AC Target* sensor. The sensor stays as it
  was.
- It appears only where the account may set the temperature, like the other climate controls.

---

## Upgrade impact

- **A new entity in Home Assistant**, *AC Target Temperature*, through MQTT discovery. Nothing
  else changes: no entity is renamed or removed, and there is no schema change.
- If you skipped 4.25.0, a security release, read [its upgrade impact](v4.25.0.md#upgrade-impact).

## Verification

- 19 new tests; the 14 that check the new code were seen failing before it. One holds the command Home
  Assistant sends equal to the Commands page's for each climate mode (AUTO, cool, heat, vent).
- Full suite in Docker on this release's code: 6242 passed, 6 skipped.

## Italiano

# Mate 4.30.0 — Home Assistant imposta la temperatura del clima

Home Assistant ora può impostare la temperatura del clima, come ha sempre potuto la pagina Comandi.

## Cosa cambia

### Home Assistant imposta la temperatura del clima ([#489](https://github.com/ProtossBlaster/leapmotor-mate/issues/489), @michapr)

Il dispositivo dell'auto in Home Assistant riceve un numero scrivibile, **AC Target Temperature**, da 18 a
32 °C a passi di 1.

- **Manda il comando della pagina Comandi.** Cambia solo la temperatura: il clima tiene modo, velocità della
  ventola e ricircolo dell'ultima lettura dell'auto. Un clima in AUTO resta in AUTO; su una T03, che ignora
  un comando in AUTO (#67), manda il raffreddamento manuale, come la pagina.
- **Mostra la temperatura impostata nell'auto**: legge lo stesso valore del sensore *AC Target*. Il sensore
  resta com'era.
- Compare solo dove l'account può impostare la temperatura, come gli altri comandi del clima.

## Impatto dell'aggiornamento

- **Una nuova entità in Home Assistant**, *AC Target Temperature*, tramite il discovery MQTT. Non
  cambia nient'altro: nessuna entità rinominata o tolta, nessun cambio di schema.
- Se hai saltato la 4.25.0, un rilascio di sicurezza, leggi [il suo impatto dell'aggiornamento](v4.25.0.md#impatto-dellaggiornamento).

## Verifica

- 19 test nuovi; i 14 che controllano il codice nuovo li ho visti fallire prima di lui. Uno tiene il
  comando di Home Assistant uguale a quello della pagina Comandi per ogni modo del clima (AUTO, freddo,
  caldo, ventilazione).
- Suite completa in Docker sul codice di questo rilascio: 6242 passati, 6 saltati.
