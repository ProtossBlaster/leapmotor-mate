# Mate 5.0.2 — 5.0.1's fix, with a module the desktop app declares

Same behaviour as 5.0.1. The 5.0.1 fix ([#495](https://github.com/ProtossBlaster/leapmotor-mate/issues/495))
used Python's `inspect` module, which is not in the list of modules the MateDesktop app is built with.
5.0.2 uses `types`, which is in that list.

---

## What changes

- Nothing you can see. A command from Home Assistant still keeps the car's PIN, as in
  [5.0.1](v5.0.1.md).
- The poller's database layer uses `types` in place of `inspect`. The 5.0.1 tag's CI went red on the test
  that compares this code's imports with the MateDesktop list; on this code that test is green.

---

## Upgrade impact

- No schema change and nothing to do.
- If you skipped 5.0.1, read [its notes](v5.0.1.md).

## Verification

- With the MateDesktop checkout mounted, the contract test fails on the 5.0.1 code (`inspect`) and passes
  on this release's code. The two #495 tests pass.
- Full suite in Docker, contract test included: 6276 passed, 6 skipped.

## Italiano

# Mate 5.0.2 — La correzione della 5.0.1, con un modulo che l'app desktop dichiara

Stesso comportamento della 5.0.1. La correzione della 5.0.1
([#495](https://github.com/ProtossBlaster/leapmotor-mate/issues/495)) usava il modulo `inspect` di Python,
che non è nella lista dei moduli con cui è costruita l'app MateDesktop. La 5.0.2 usa `types`, che in
quella lista c'è.

## Cosa cambia

- Niente di visibile. Un comando da Home Assistant tiene sempre il PIN dell'auto, come nella
  [5.0.1](v5.0.1.md#italiano).
- Il livello database del poller usa `types` al posto di `inspect`. La CI del tag 5.0.1 era rossa sul test
  che confronta gli import di questo codice con la lista di MateDesktop; su questo codice quel test è
  verde.

## Impatto dell'aggiornamento

- Nessun cambio di schema e niente da fare.
- Se hai saltato la 5.0.1, leggi [le sue note](v5.0.1.md#italiano).

## Verifica

- Con la cartella di MateDesktop montata, il test del contratto fallisce sul codice della 5.0.1
  (`inspect`) e passa sul codice di questo rilascio. I due test della #495 passano.
- Suite completa in Docker, test del contratto compreso: 6276 passati, 6 saltati.
