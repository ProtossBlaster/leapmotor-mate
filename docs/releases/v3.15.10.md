# v3.15.10 — Notes from every joined trip segment

This patch fixes [#279](https://github.com/ProtossBlaster/leapmotor-mate/issues/279).

## What changes

- A joined trip continues to show its primary note in the editable note field.
- Notes belonging to later trip segments are shown below it in chronological order.
- Each additional note is separated and labelled with the start and end time of its segment.
- Empty later-segment notes are omitted rather than adding blank separators.
- Notes remain stored on their original trip rows; joining a trip never copies or rewrites them.
- Splitting the journey restores every trip with its original note unchanged.

This preserves the existing reversible merge model while making automatic notes from every
part of a joined journey visible. Generating or editing the primary journey note does not erase
the notes retained by its other segments.

## Verification

Focused note and merged-summary verification passed **14 tests**. The complete project suite
passed **3,280 tests**, with **8 intentional skips**. The remaining output consists of dependency
deprecation warnings from the current FastAPI, Starlette and Python combination. Test data was
synthetic and no live vehicle-cloud command was sent.

## Update and rollback

- Back up Mate using its existing backup feature before upgrading.
- Docker and Home Assistant use the normal image update while retaining the existing data volume.
- MateDesktop receives the payload through its existing updater; no new installer is needed.
- This release changes no database schema or stored data and needs no migration.
- Rolling back to v3.15.9 requires no data conversion; later-segment notes remain stored but are
  no longer displayed on the joined trip page.

## Italiano

Questo aggiornamento corregge la visualizzazione delle note nei viaggi uniti. La nota principale
resta modificabile come prima, mentre le note automatiche dei segmenti successivi vengono mostrate
in ordine cronologico, separate e accompagnate dall'orario del relativo tratto.

Le note non vengono copiate o riscritte: ciascuna resta salvata nel viaggio originale. Separando
nuovamente i viaggi, tutte le note vengono quindi ripristinate senza modifiche. Non cambia lo schema
del database e non vengono convertiti o cancellati dati.
