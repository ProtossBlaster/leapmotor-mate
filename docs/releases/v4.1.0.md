# Mate 4.1.0 — charging places and map controls

Joint release of #315 (PR323) and #288 (PR324).

- **Map:** show/hide frequent places; the choice is remembered in each browser.
- **Costs → Charging places:** configure private places per vehicle with a name, map coordinates, radius and fixed price per kWh. New live AC sessions are matched only with fresh, stationary, unambiguous GPS evidence.
- Each charge keeps its place name and tariff snapshot. Editing a place does not reprice history. Closed, unmerged sessions support manual assignment; manual totals and free charges remain authoritative.
- Spending totals are grouped by place. Guards prevent cross-vehicle edits and merges between different place/rate snapshots. All eight locales are covered.

## Upgrade and limits

Docker and both Home Assistant add-ons use the same 4.1.0 payload; Desktop uses its existing Mate payload update mechanism. The Desktop shell and independent API package do not require a separate version bump. Existing credentials, migration decisions and cloud commands are unchanged.

The database gains a table and nullable fields automatically. Existing history is not assigned or repriced automatically. Keep a pre-upgrade backup: older versions can read the database but do not understand place tariffs when editing charges. Restoring a backup discards data recorded since that backup.

This release supports fixed tariffs for private places. Without measured charger energy, costs are estimates based on battery energy; it does not infer charging losses, public roaming/subscription prices or dynamic private-place tariffs. Offline reconstructed sessions are not assigned from the vehicle's current position.

## Italiano

Rilascio congiunto delle #315 e #288: interruttore dei luoghi frequenti sulla mappa e **Costi → Luoghi di ricarica**, con luoghi privati distinti per auto, selezione sulla mappa, raggio e tariffa fissa. Il riconoscimento automatico usa solo nuove sessioni AC con GPS recente, auto ferma e una sola zona compatibile.

Ogni ricarica conserva luogo e tariffa; lo storico non viene ricalcolato quando si cambia un prezzo. Sono disponibili assegnazione manuale e riepilogo delle spese. Importi manuali e ricariche gratuite vengono preservati. Corrette anche le protezioni per cambio auto e ricariche unite.

Aggiornamento ordinario senza riconfigurare credenziali o migrazione, condiviso da Docker, add-on e payload Desktop. Conservare il backup precedente. Le tariffe sono fisse e private: senza misura della colonnina i costi sono stime; abbonamenti, roaming e tariffe dinamiche per luogo non sono inclusi.
