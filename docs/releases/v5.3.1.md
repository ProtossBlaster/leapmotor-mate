# Mate 5.3.1 — Croatian

Mate speaks Croatian, thanks to @daleonidas.

---

## What changes

### Croatian is the tenth language ([#506](https://github.com/ProtossBlaster/leapmotor-mate/pull/506), @daleonidas)

*Settings → Language → Hrvatski*, and the setup wizard follows a browser set to Croatian. Every page,
the setup wizard and the service schedule are translated.

---

## Upgrade impact

- **Schema:** unchanged.
- **Home Assistant:** unchanged.
- Nothing changes for anyone who does not pick Croatian.

## Verification

- Full suite in Docker: 6403 passed, 7 skipped, on the exact tree of this release.
- The Croatian file has every key of the English one, with the same placeholders.
- On a copy of a real B10 database set to Croatian, the main pages (Overview, Events, Trips, a trip, Charges,
  Statistics, Settings, Map, Battery, Maintenance) answer 200 with no untranslated key.

# Mate 5.3.1 — Croato

Mate parla croato, grazie a @daleonidas.

## Cosa cambia

### Il croato è la decima lingua ([#506](https://github.com/ProtossBlaster/leapmotor-mate/pull/506), @daleonidas)

*Impostazioni → Lingua → Hrvatski*, e la procedura guidata segue un browser impostato in croato. Ogni
pagina, la procedura guidata e il programma di manutenzione sono tradotti.

## Impatto dell'aggiornamento

- **Schema:** invariato.
- **Home Assistant:** invariato.
- Non cambia niente per chi non sceglie il croato.

## Verifica

- Suite completa in Docker: 6403 passati, 7 saltati, sull'albero esatto di questa versione.
- Il file croato ha tutte le chiavi di quello inglese, con gli stessi segnaposto.
- Su una copia di un database vero di una B10 impostata in croato, le pagine principali (Panoramica, Eventi,
  Viaggi, un viaggio, Ricariche, Statistiche, Impostazioni, Mappa, Batteria, Manutenzione) rispondono 200
  senza chiavi non tradotte.
