# Mate 4.0.0-rc.1

## English

Candidate migration to independent MATE-API with V3 commands. A consistent pre-upgrade backup is stored beside the database. Docker and HA share the same image; Desktop uses the same source payload. Cloud trip import is optional. Command qualification is B10 only. This is an opt-in candidate, not an automatic stable update. See ../MIGRATION-4.md for provisioning and rollback.

## Italiano

Migrazione candidata al client indipendente MATE-API con comandi V3. Backup coerente prima dell'aggiornamento, stessa immagine Docker/HA e stesso codice per Desktop. Importazione viaggi cloud opzionale. Comandi qualificati solo per B10. Installazione volontaria, senza aggiornamento automatico degli utenti stabili. Vedere ../MIGRATION-4.md per configurazione e rollback.
